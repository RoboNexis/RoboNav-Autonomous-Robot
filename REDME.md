# RoboNav 🤖
Autonomous Obstacle Detection and Avoidance Robot

## Overview
RoboNav is a Level-1 autonomous robot
that detects obstacles and changes its direction
by scanning the surrounding area.

## Features
- Obstacle detection
- Left and right scanning
- Automatic direction selection
- Autonomous movement

## Technologies
- Arduino Programming
- Embedded Systems
- Ultrasonic Sensing
- Motor Control

## Components
See Components.txt.

## Working Principle
The ultrasonic sensor measures the distance
from nearby obstacles. A servo scans left and
right when an obstacle is detected. Arduino
compares the distances and controls the motors
to select a clearer direction.
